# Ali & Hamna Mehndi Invitation

This folder is ready for GitHub Pages.

## Upload

1. Extract the ZIP file on your computer.
2. Open your GitHub repository and choose **Add file → Upload files**.
3. Upload every extracted file together, keeping `index.html` at the repository root.
4. Commit the upload.
5. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

Do not upload the ZIP itself as the website. GitHub Pages needs the extracted files.
